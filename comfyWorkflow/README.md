# Workflows ComfyUI

Déposez ici un ou plusieurs workflows ComfyUI au format **API JSON**.

Dans ComfyUI, activez le mode développeur puis utilisez **Save (API Format)**. L'application liste automatiquement les fichiers `.json` de ce dossier. Le workflow sélectionné est envoyé à l'endpoint `/prompt` de ComfyUI lorsqu'un nouveau visiteur est détecté et que l'intégration est activée dans les réglages.

Les workflows exportés uniquement au format visuel de l'interface ComfyUI ne sont pas directement exécutables par l'API.
